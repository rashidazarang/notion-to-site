# Neuropsychological Report Summary


## **Neuropsychological Report Summary**


**Date of Evaluation Start:** July 22, 2024


### **Tests Applied:**

- Free and Cued Selective Reminding Test (FCSRT)
- Beck Depression Inventory (BDI)
- Paced Auditory Serial Addition Test (PASAT)
- Behavioural Assessment of Dysexecutive Syndrome (BADS)
- Wechsler Adult Intelligence Scale (WAIS-IV)
- Rivermead Behavioural Memory Test (RBMT)
- Wisconsin Card Sorting Test (WCST)
- Stroop Test (STROOP)
- Trail Making Test (TMT-A, B)

---


### **Neuropsychological Results:**


**Attention:** Performance within the normal range for sustained and selective attention. Slight difficulty noted in symbol search tasks.


**Memory:** Verbal memory is within the normal range. Logical memory tasks were affected, though this may have been influenced by a misinterpretation of instructions during the test.


**Executive Function:** Alternating and divided attention are preserved, with slight impairments observed in working memory and abstraction.


**Verbal Fluency:** Slight to moderate difficulty in semantic verbal fluency tasks.


**Planning:** Slight difficulties in planning tasks, especially when under time pressure.


---


### **Conclusions:**

- Mild alteration in executive functions (working memory, abstraction, processing speed).
- Moderate alteration in executive functions (inhibitory control, impacting planning).
- Overall cognitive performance is consistent with a mild ADHD (mixed type) diagnosis.

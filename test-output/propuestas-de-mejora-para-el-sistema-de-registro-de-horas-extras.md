# Propuestas de Mejora para el Sistema de Registro de Horas Extras


[**← Back to blog**](/4188dc4ee2494e7fb38b8156efdcdd31)


## **Propuestas de Mejora para el Sistema de Registro de Horas Extras**


![image](notion:899d4ad3-b9fa-469c-8e0b-19bcd00f2b44)


### **1. División del Sistema en Dos Partes**

- **Para el empleado**: Permitir que cada empleado ingrese su solicitud de horas extras y firme digitalmente desde su propio dispositivo.
- **Para el gerente**: Crear un sistema específico para los gerentes, donde puedan revisar todas las solicitudes del día y aprobar o rechazar cada una de manera consolidada.

### **2. Flujo Simplificado de Aprobación**


En vez de que el gerente firme cada solicitud en el celular del empleado, podrá acceder a su propio sistema, revisar las solicitudes del día y dar una aprobación rápida con ✅ o un rechazo con ❌. Esto reduce el tiempo que el gerente debe invertir y centraliza la aprobación de manera eficiente.


### **3. Mejora en la Revisión de Solicitudes**


El sistema del gerente incluirá:

- Un espacio para **“Notas adicionales”** para cada solicitud.
- La opción de **“Cancelar solicitud”** si considera que la petición no es válida o no cumple con los requisitos.

### **4. Bitácora Consolidada**


El sistema generará una **bitácora digital** que recopile:

- Registros de empleados y gerentes.
- Datos como tiempo de registro, área de trabajo, aprobación/rechazo por parte del gerente.
- Filtros para análisis y métricas a lo largo del tiempo.

### **5. Facilidad de Uso**


Los gerentes solo necesitarán revisar el sistema **una vez al día** para gestionar todas las solicitudes pendientes. Esto reduce las interrupciones y facilita una gestión eficiente de las horas extras.
